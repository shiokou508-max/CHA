# やめログ（Yamelog）開発計画書

> 「I Am Sober」のように、やめたい習慣を“やめ続ける”ことを支えるスマホ向け PWA アプリ

- 作成日: 2026-10-08
- 対象: iPhone（Safari）/ Android（Chrome）のホーム画面アプリ、PC ブラウザ
- 配置: リポジトリ内 `yamelog/` ディレクトリ（既存の HSK 学習アプリとは独立）

---

## 1. 目的とコンセプト

| 項目 | 内容 |
| --- | --- |
| 目的 | お酒・タバコ・SNS などの「やめたい習慣」を断つ期間を可視化し、毎日の小さな達成を積み重ねて継続を支援する |
| コンセプト | **「今日も、やめている。」** — 責めない・比べない・続けられる |
| 参考 | I Am Sober（禁酒カウンター、毎日の誓い、マイルストーン、節約額表示） |
| 方針 | アカウント登録なし・サーバー通信なし・データは端末内のみ（プライバシー最優先） |

### ターゲットユーザー
- 何かをやめたいが、意志だけに頼ると続かない人
- 記録や数字を見るとモチベーションが上がる人
- 他人に知られずにひっそり取り組みたい人（ログイン不要・端末内保存）

## 2. 機能一覧

### 2.1 MVP（今回実装する範囲）

| # | 機能 | 内容 |
| --- | --- | --- |
| F1 | やめる習慣の登録 | プリセット（お酒・タバコ・SNS・ゲーム・ギャンブル・甘いもの・カフェイン・夜更かし・買い物）またはカスタム。名前・絵文字・開始日時・1日あたりの費用・1日あたりの時間・やめる理由を登録。複数習慣を同時に管理できる |
| F2 | リアルタイム経過カウンター | 「○日 ○時間 ○分 ○秒」を毎秒更新で表示 |
| F3 | 節約額・取り戻した時間 | 1日の費用×経過日数、1日の時間×経過日数を自動計算 |
| F4 | マイルストーン | 1日 / 3日 / 1週間 / 2週間 / 30日 / 90日 / 半年 / 1年 … 到達でお祝い演出。次の目標までの進捗リング |
| F5 | 毎日の誓い & 振り返り | 朝「今日もやめる」と誓う → 夜「今日はやめられた？」と振り返る。誓いの連続日数を表示 |
| F6 | スリップ（再発）の記録 | 責めないメッセージとともにカウンターをリセット。きっかけ・メモを記録し、過去の連続記録（ストリーク）として履歴に残す。最長記録・累計クリーン日数は保持 |
| F7 | 衝動 SOS | 「つらい時」ボタン → 呼吸ガイド（ボックス呼吸）、経過タイマー、自分の「やめる理由」を表示。衝動の強さ・きっかけを記録し「乗り越えた」回数をカウント |
| F8 | 記録（カレンダー・統計） | 月カレンダーにクリーン日／スリップ日／誓い／日記を表示。衝動のきっかけランキング |
| F9 | 日記 | 気分（5段階）＋テキスト。習慣ごとにタグ付け可 |
| F10 | 設定 | 通貨記号、テーマ（自動/ライト/ダーク）、データの書き出し・読み込み（JSON バックアップ）、全データ削除 |
| F11 | PWA | ホーム画面に追加、オフライン動作、アップデート通知、アプリショートカット（SOS） |

### 2.2 今後の拡張（Phase 2 以降）

- プッシュ通知による誓いのリマインダー（※後述の制約参照。プッシュサーバーが必要）

- PIN / 生体認証によるアプリロック
- 実績バッジのシェア画像生成
- 端末間同期（任意のクラウドバックアップ）
- 多言語対応（英語）

## 3. 画面構成と遷移

```
初回起動
  └─ ようこそ → 習慣の登録 → ホーム

下部タブ: [ホーム] [記録] [日記] [設定]

ホーム (#/)
  ├─ 今日の誓い / 振り返りカード
  ├─ 習慣カード（ライブカウンター・次の目標） ── タップ → 習慣詳細
  ├─ ＋ 習慣を追加 → 習慣の登録/編集
  └─ SOS ボタン（常時表示） → 衝動 SOS

習慣詳細 (#/habit/:id)
  ├─ 大きなカウンター + 進捗リング
  ├─ 統計（節約額・時間・最長記録・累計・スリップ回数・乗り越えた衝動）
  ├─ やめる理由
  ├─ マイルストーン一覧
  ├─ 連続記録の履歴
  └─ [編集] [スリップを記録]

衝動 SOS (#/sos)        … 呼吸ガイド・理由・衝動の記録
記録 (#/records)        … カレンダー・統計
日記 (#/journal)        … 日記の一覧・追加
設定 (#/settings)       … 各種設定・バックアップ・インストール案内
習慣の登録/編集 (#/new, #/edit/:id)
```

- ルーティングは **ハッシュ方式**（`#/...`）。GitHub Pages 等の静的ホスティングでもサーバー設定不要で、戻るボタンも機能する。
- モーダルは下から出る「ボトムシート」に統一（スリップ記録・日記作成・確認ダイアログ・お祝い）。

## 4. データモデル

`localStorage` のキー `yamelog:v1` に JSON で保存する。

```jsonc
{
  "version": 1,
  "settings": {
    "currency": "¥",
    "theme": "auto",          // auto | light | dark
    "onboarded": true
  },
  "habits": [{
    "id": "h_xxx",
    "name": "お酒",
    "emoji": "🍺",
    "color": "#2a9d8f",
    "startedAt": 1759900000000,     // 現在の連続記録の開始時刻 (ms)
    "createdAt": 1759900000000,
    "costPerDay": 800,              // 1日あたりの費用
    "minutesPerDay": 90,            // 1日あたりに使っていた時間（分）
    "reasons": ["健康のため", "家族との時間"],
    "history": [{ "start": 0, "end": 0 }],          // 過去の連続記録
    "relapses": [{ "at": 0, "trigger": "ストレス", "note": "" }],
    "celebrated": 30                // お祝い済みの最大マイルストーン（日）
  }],
  "checkins": {
    "2026-10-08": { "pledgedAt": 0, "reviewedAt": 0, "result": "clean" }  // clean | slip
  },
  "urges": [{ "id": "u_xxx", "at": 0, "habitId": "h_xxx", "intensity": 3, "trigger": "退屈", "outcome": "resisted" }],
  "journal": [{ "id": "j_xxx", "at": 0, "mood": 4, "text": "…", "habitId": null }]
}
```

### 計算ロジック
- 経過時間 = `now - startedAt`
- 節約額 = `costPerDay × 経過日数(小数)`、取り戻した時間 = `minutesPerDay × 経過日数(小数)`
- 最長記録 = `max(history の各期間, 現在の連続記録)`
- 累計クリーン時間 = `history の合計 + 現在の連続記録`
- 次のマイルストーン進捗 = `(経過 - 直前の目標) / (次の目標 - 直前の目標)`
- 過去日付で登録した場合、すでに到達済みのマイルストーンはお祝いしない（`celebrated` を初期化）

### データ移行
- `version` フィールドを持たせ、将来のスキーマ変更時はマイグレーション関数で変換する。
- 読み込み時に欠損フィールドを既定値で補完し、壊れた JSON でもアプリが落ちないようにする。

## 5. 技術構成

| 項目 | 採用技術 | 理由 |
| --- | --- | --- |
| 言語 | HTML / CSS / JavaScript（ES Modules） | ビルド不要。既存リポジトリと同じ素の構成で、置くだけで動く |
| フレームワーク | なし（自前の軽量レンダラー + イベント委譲） | 依存ゼロ・高速・オフラインに強い |
| 保存 | localStorage + `navigator.storage.persist()` | データ量が小さく同期 API で扱いやすい。永続化を要求して削除されにくくする |
| オフライン | Service Worker（アプリシェルをプリキャッシュ、キャッシュ優先） | 電波がなくても起動できる |
| インストール | Web App Manifest、`beforeinstallprompt`（Android）、iOS 向け案内 | ホーム画面アプリとして起動 |
| フォント | システムフォント（ヒラギノ / Noto Sans JP） | 外部読み込みなしでオフライン動作 |
| テスト | `node --test`（ロジックの単体テスト）+ Playwright（E2E・スクリーンショット） | |

### ファイル構成

```
yamelog/
├─ PLAN.md               … 本計画書
├─ README.md             … 使い方・公開方法
├─ index.html            … アプリシェル
├─ manifest.webmanifest  … PWA マニフェスト
├─ sw.js                 … Service Worker
├─ package.json          … テスト用（"type": "module"）
├─ css/style.css
├─ js/
│  ├─ app.js             … 起動・ルーター・画面描画・イベント
│  ├─ store.js           … データの読み書き・更新操作
│  ├─ logic.js           … 時間計算・マイルストーン・統計（純粋関数）
│  └─ presets.js         … 習慣プリセット・きっかけ・励ましメッセージ
├─ icons/                … アプリアイコン（SVG / PNG 各サイズ / maskable）
└─ tests/                … 単体テスト・E2E スクリプト
```

## 6. UI / デザイン方針

- **トーン**: 落ち着いたティール（緑青）を基調に、マイルストーンはゴールドで祝福。赤は使いすぎない（スリップも「失敗」ではなく「記録」として扱う）
- **文言**: 責めない・励ます。例「スリップは失敗ではありません。ここからまた始めましょう。」
- **ダークモード**: OS 設定に追従（手動切替も可）
- **スマホ最適化**: 片手で押せる下部タブ、44px 以上のタップ領域、iPhone のノッチ／ホームバー（safe-area）対応
- **アクセシビリティ**: aria-label、十分なコントラスト、`prefers-reduced-motion` で演出を抑制
- **SOS ボタン**: どの画面からも 1 タップで届く位置に常設

## 8. 制約・リスクと対策

| リスク | 対策 |
| --- | --- |
| iOS では PWA のプッシュ通知にサーバーが必要で、端末内だけで「毎朝の通知」を確実に出す方法がない | MVP では通知は実装せず、アプリを開いた時に誓い／振り返りカードを最上部に出す。通知は Phase 2 |
| ブラウザのデータ削除・端末変更でデータが消える | JSON 書き出し/読み込みのバックアップ機能、`storage.persist()` の要求、ホーム画面追加の推奨 |
| Safari（未インストール時）は一定期間未使用でストレージが消去される場合がある | 設定画面でホーム画面追加を案内 |
| 時刻・タイムゾーンの扱い | 内部はすべて UTC ミリ秒で保持し、日付キー（YYYY-MM-DD）は端末のローカル日付で生成 |
| 医療的助言と誤解される表現 | 健康効果の断定表現は避ける。設定画面に「医療の代わりではない」旨と相談窓口の案内を記載 |

## 10. テスト計画

### 単体テスト（`node --test`）
- 経過時間の分解（日・時・分・秒）
- マイルストーンの「直前/次」と進捗率
- 節約額・取り戻した時間の計算
- スリップ記録時の履歴追加・最長記録・累計の計算
- 誓いの連続日数（日付またぎ・欠落日）
- 壊れたデータ／古いデータの読み込み時の補完

### E2E（Playwright, iPhone 相当の画面幅）
1. 初回起動 → 習慣を登録 → ホームにカウンターが表示され秒が進む
2. 誓いを立てる → 振り返りで「やめられた」
3. スリップを記録 → カウンターがリセットされ履歴に残る
4. SOS → 衝動を記録 → 「乗り越えた」回数が増える
5. 日記を書く → 一覧とカレンダーに反映
6. データ書き出し → 全削除 → 読み込みで復元
7. Service Worker 登録後、オフラインで再読み込みしても表示される
8. コンソールエラーが出ないこと
