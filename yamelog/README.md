# やめログ（Yamelog）

**やめたい習慣を、今日もやめている。**

「I Am Sober」のように、お酒・タバコ・SNS などの“やめたい習慣”をやめ続けるためのスマホ向け PWA です。
登録不要・データは端末内だけに保存されます。計画書は [PLAN.md](PLAN.md) を参照してください。

## 主な機能

| | |
| --- | --- |
| ⏱️ 経過カウンター | やめてからの時間を「○日 ○時間 ○分 ○秒」で毎秒表示。複数の習慣を同時に管理 |
| 💰 節約額・時間 | 1日あたりの費用・時間から、節約できたお金と取り戻した時間を自動計算 |
| 🏅 マイルストーン | 1日〜10年の18段階。到達するとお祝い（シェアも可能） |
| 🤝 毎日の誓い | 朝に「今日もやめる」と誓い、夜（17時以降）に振り返る。連続日数を表示 |
| 🌱 スリップ記録 | 責めないメッセージとともにリセット。きっかけ・メモと過去の記録は履歴に残る |
| 🆘 衝動SOS | ボックス呼吸ガイド、やめる理由の表示、衝動の強さ・きっかけの記録 |
| 📅 記録 | カレンダー（クリーン日・スリップ日・誓い・日記）、きっかけランキング |
| 📝 日記 | 気分（5段階）とメモ |
| ⚙️ 設定 | テーマ（自動/ライト/ダーク）、通貨、バックアップの書き出し・復元、全削除 |
| 📲 PWA | ホーム画面に追加、オフライン動作、更新通知、ショートカット（SOS） |

## 使い方（スマホ）

1. 公開した URL を開く（HTTPS が必要。GitHub Pages など）
2. **iPhone**: Safari の共有ボタン →「ホーム画面に追加」
   **Android**: Chrome のメニュー →「アプリをインストール」（アプリ内の「追加」ボタンからも可）
3. ホーム画面のアイコンから起動。以降はオフラインでも使えます

> ホーム画面に追加しておくと、ブラウザによるデータ自動削除の対象になりにくくなります。機種変更の前には「設定 → バックアップを書き出す」を使ってください。

## ローカルで動かす

ビルド不要です。`yamelog/` を静的サーバーで配信するだけで動きます。

```bash
cd yamelog
npx serve -l 4173 .       # または: python3 -m http.server 4173
# → http://localhost:4173/
```

## GitHub Pages で公開する

1. このブランチを `main` にマージ
2. リポジトリの **Settings → Pages** で「Deploy from a branch」→ `main` / `/(root)` を選択
3. `https://<ユーザー名>.github.io/<リポジトリ名>/yamelog/` で公開されます

パスはすべて相対指定なので、サブディレクトリに置いてもそのまま動きます。

## テスト

```bash
cd yamelog
npm test            # ロジック・データストアの単体テスト（node --test）
npm run test:e2e    # Playwright によるスマホ幅の E2E テスト（Chromium が必要）
```

E2E は初回登録 → 誓い → 詳細 → スリップ → SOS → 日記 → 記録 → テーマ → バックアップ/復元 → お祝い → 夜の振り返り → オフライン起動 → 320px 幅のレイアウトまで通しで確認します。
`SCREENSHOT_DIR=/path/to/dir npm run test:e2e` で各画面のスクリーンショットを保存できます。

## 更新するとき

`sw.js` がアプリ一式をキャッシュしています。ファイルを変更したら **`sw.js` の `VERSION` を上げてください**。利用者の画面に「新しいバージョンがあります → 更新」が表示されます。

アイコンを作り直す場合は `node tools/generate-icons.mjs` を実行します。

## ファイル構成

```
yamelog/
├─ index.html            アプリシェル
├─ manifest.webmanifest  PWA マニフェスト
├─ sw.js                 Service Worker（オフライン対応）
├─ css/style.css         スタイル（ライト/ダーク）
├─ js/app.js             ルーター・画面・イベント
├─ js/store.js           データ保存（localStorage）と更新処理
├─ js/logic.js           時間計算・マイルストーン・統計（純粋関数）
├─ js/presets.js         習慣プリセット・定型文
├─ icons/                アプリアイコン
├─ tools/                アイコン生成スクリプト
└─ tests/                単体テスト・E2E
```

## プライバシー

データはすべてこの端末のブラウザ（localStorage）に保存され、外部サーバーには一切送信されません。
